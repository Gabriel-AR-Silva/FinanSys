# Mode — Exploratory

Uso: quando o usuário não sabe exatamente o que procura.

Características:
- expandir espaço de hipóteses
- não ficar preso aos exemplos do usuário
- buscar adjacências
- procurar sinais fracos
- trazer achados óbvios, não óbvios e contraintuitivos
- distinguir oportunidade real de ruído
- permitir desvios relevantes desde que justificados
