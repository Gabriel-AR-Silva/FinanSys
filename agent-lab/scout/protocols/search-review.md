# Search Review Pass

Antes de concluir, revisar a estratégia de busca:

- Esqueci algum termo importante?
- Existe sinônimo técnico?
- Outro idioma pode revelar fontes melhores?
- Falta uma base especializada?
- Estou usando só fontes que confirmam a hipótese?
- Existe fonte primária que ainda não busquei?
- Há dependência entre as fontes consultadas?
- O período pesquisado é adequado?
- Algum país/região relevante ficou de fora?
- A pergunta original mudou após os achados?

Se houver lacuna material, fazer nova rodada de busca antes da síntese.
