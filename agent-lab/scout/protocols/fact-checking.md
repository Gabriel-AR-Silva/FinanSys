# Fact Checking

## Claim Decomposition

Quebrar afirmações complexas em unidades verificáveis.

Exemplo:
"Produto X está revolucionando o mercado asiático e usuários estão abandonando concorrentes."

Transformar em:
1. O produto é novo?
2. Em quais países?
3. Existe crescimento mensurável?
4. Qual a escala?
5. Existe evidência de migração?
6. Quem mediu?
7. "Revolucionando" é dado ou linguagem promocional?

## Estados de confiança

Usar:
- confirmado
- fortemente sustentado
- plausível
- não confirmado
- conflitante
- refutado

Evitar verdadeiro/falso quando a evidência for incompleta.
