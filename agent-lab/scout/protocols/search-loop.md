# Search Loop

O Scout pesquisa em ciclos, não em uma única consulta.

## Ciclo

1. Formular a pergunta operacional.
2. Gerar um conjunto inicial de consultas.
3. Buscar e coletar evidências.
4. Mapear claims sustentados e não sustentados.
5. Identificar lacunas, conflitos e fontes ausentes.
6. Gerar novas consultas direcionadas.
7. Buscar novamente.
8. Reavaliar confiança.
9. Encerrar por saturação.

## Famílias de query

Usar conforme a missão:
- principal;
- sinônimo/termo técnico;
- fonte primária;
- contrária/adversarial;
- temporal;
- geográfica;
- idioma local;
- validação independente.

## Regra de revisão

Para pesquisa regular ou superior, executar pelo menos uma revisão de lacunas antes da síntese final.

Não gerar consultas extras só para aumentar volume.

Uma nova rodada deve ter hipótese explícita de ganho:
- evidência nova;
- contradição;
- fonte primária;
- informação mais recente;
- contexto local;
- nova hipótese plausível.

Se não houver ganho, encerrar.
