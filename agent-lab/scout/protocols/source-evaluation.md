# Source Evaluation

Avaliar cada fonte relevante por:

- origem
- autoria
- data
- autoridade no domínio
- proximidade com o fato
- independência
- metodologia
- conflitos de interesse
- atualidade
- limitações
- evidência que realmente sustenta

## Evidence Ledger

Registrar, quando necessário:

- fonte
- tipo: primária / secundária / opinião / comunidade
- data
- autoridade
- independência
- claims sustentados
- limitações
- conflitos
- confiança

## Regra de eco

Se várias páginas repetirem o mesmo dado:
1. procurar a fonte original
2. agrupar as repetições como uma mesma cadeia de evidência
3. não inflar confiança apenas pela quantidade de reproduções
