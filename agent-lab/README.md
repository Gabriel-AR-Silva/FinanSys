# Agent Lab

Temporary workspace for cloning, testing, and evolving reusable AI agents without changing the existing FinanSys agents.

## Purpose

- Keep current FinanSys agents untouched.
- Copy selected agents here as starting points.
- Generalize and improve them independently.
- Test protocols, domain modules, handoffs, and output contracts.
- Later migrate mature agents to a dedicated private repository if desired.

## Initial direction

The first agent to evolve here will be **Scout**, focused on reusable research methodology, source quality, fact-checking, uncertainty handling, and domain-specific research modules.
